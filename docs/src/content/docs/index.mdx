## The problem

A typical app ends up with three different data layers: a REST client here, a GraphQL client there, raw WebSocket handling for realtime. Each has its own error handling and its own shape. Swap one backend and the business code that calls it has to change too.

<TabItem label="Without nexdk">
```ts

if (!res.ok) throw new Error(`HTTP ${res.status}`)
```

<TabItem label="With nexdk">
```ts
await sdk.lomkit.products.get({})
await sdk.nhost.products.query({})
sdk.supabase.messages.subscribe({}, handler)
```
</TabItem>
</Tabs>

Business code declares **resources**. The protocol behind them (Laravel/Lomkit, Hasura, Supabase) becomes an interchangeable detail.

## Quickstart

nexdk is not published to npm yet. Clone [the repository](https://github.com/techmefr/nexdk) and run `pnpm install && pnpm build`.

```ts
import { createSdk, defineResource } from 'nexdk'
import { LomkitDriver } from '@nexdk/driver-lomkit'
import { z } from 'zod'

const product = defineResource({
  name: 'products',
  schema: z.object({ id: z.number(), name: z.string(), price: z.number() }),
})

export const sdk = createSdk({
  drivers: { lomkit: new LomkitDriver({ baseUrl: 'https://api.example.com' }) },
  resources: { lomkit: { products: product } },
})

const { data, error } = await sdk.lomkit.products.get({
  search: { filters: [{ field: 'price', operator: '<', value: 100 }] },
})
```

Once `error` is checked, `data.data` is typed as `{ id: number; name: string; price: number }[]`. A call never throws unless you pass `throw: true` to `createSdk`.

## What it does not do

`nexdk` is a call grammar and a driver contract, not a cache. It does not dedupe requests or revalidate on focus. Use [TanStack Query](https://tanstack.com/query) or [SWR](https://swr.vercel.app) on top of a driver call if you need that.

## Ecosystem

| Project | Role |
|---|---|
| [neXdk](https://github.com/techmefr/nexdk) | One resource grammar for REST, GraphQL and WebSocket backends. |
| [beepr](https://github.com/techmefr/beepr) | Typed notifications and debug output. |
| [shamock](https://github.com/techmefr/shamock) | Mock `fetch` without any dependency. |
| [dialectr](https://github.com/techmefr/dialectr) | Universal query builder (lomkit, PocketBase, Strapi). |

Each works alone. See [Ecosystem](/nexdk/guides/ecosystem/) to combine them.
